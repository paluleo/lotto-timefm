TimesFM·연도/주차 통계 조합 실험

실제 추론이 확인되면 1~45번의 회차별 등장 시계열 결과와 과거 통계를 결합한 번호를 표시합니다.

실험 결과 확인 중

실제 추론 기록과 현재 공식 추첨 데이터가 일치하는지 확인하고 있습니다.

고정 결합 규칙: TimesFM 번호 순위 50% + 전체 입력 기간 출현 순위 30% + 같은 ISO 주차 출현 순위 20%. 이 비율은 실험 설정이며 당첨 확률이 아닙니다. 각 게임의 6개 번호를 중복 없이 가중 추출한 결과입니다.

통계 순위의 기준은 주 번호 포함 비율 75% + 2등 가능 조합 포함 비율 25%입니다. 표본이 적은 주차는 20회 추첨에 해당하는 균등 사전값으로 완화합니다. 두 결합 비율 모두 검증 성적을 보고 조정하지 않은 고정 실험 규칙입니다.

연도·주차별 관측 통계

주 번호와 보너스 비율의 분모는 추첨 횟수입니다. 2등 가능 조합 포함 비율의 분모는 추첨 횟수 × 6개 파생 조합입니다. 6개 파생 조합을 독립적인 추첨 6회로 간주하지 않습니다. 관측 비율은 미래 당첨 확률이 아니며, 연도와 주차는 토요일 추첨일의 ISO 기준입니다.

통계와 생성 방식을 읽는 법

기존 EMA·빈도 통계 생성기는 과거 당첨번호 합계의 지수이동평균(EMA)과 전체 평균을 65:35로 혼합하고, 번호별 출현 빈도를 이용합니다. 이 기존 생성기에서 Google TimesFM 모델은 사용하지 않습니다. 실제 TimesFM과 1등·2등 가능 조합 통계를 결합한 번호는 별도 실험 구역에서 확인할 수 있습니다.

합계 범위는 혼합값의 ±12를 기준으로 정한 조합 생성용 설정이며 예측 신뢰구간이 아닙니다. 생성기는 가중 무작위 추출로 6개의 서로 다른 번호를 고른 뒤 표시된 합계 범위와 고정수 조건을 확인합니다. 시도 횟수 안에 조건을 만족하지 못하면 번호 대신 실패 안내를 표시합니다.

과거에 자주 나온 번호가 다음 회차에도 더 잘 나온다는 근거는 없습니다. 이 생성 방식의 당첨 확률 향상은 입증되지 않았습니다. 실제 당첨 결과는 동행복권에서 직접 확인하세요.

이 사이트는 데이터 시각화와 번호 조합을 위한 도구입니다. 당첨을 보장하지 않으며, 확인되지 않은 추첨 결과는 표시하지 않습니다.
